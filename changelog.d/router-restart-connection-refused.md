- **A service restart no longer refuses Codex until LiteLLM has finished starting.** The router used to start only after the gateway was healthy, so its port stayed closed for the whole cold start and Codex could run out of retries with `stream disconnected before completion: Connection refused`. The router now starts alongside the gateway. Native turns are served straight away, and routed turns wait up to 60 seconds (`CODEX_ROUTER_STARTUP_HOLD_MS`) for the local dependencies during startup only, so a later gateway crash behaves as before. A router that cannot bind now fails startup immediately instead of waiting out the gateway's allowance.
