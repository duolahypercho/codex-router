- **Runcrate is now a catalog-only provider.** Its OpenAI-compatible API (`https://api.runcrate.ai/v1`, key `RUNCRATE_API_KEY`, endpoint override `RUNCRATE_API_BASE_URL`) is registered for routing and credential isolation like the other catalog-only providers. It ships no preselected models: store a key, then run `./bin/curate-models runcrate` to choose models from its live catalog.
