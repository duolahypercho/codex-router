- **Windows tray fix**: `tray uninstall` no longer fails with "task exists or is unreadable" when the scheduled task query times out or returns an error. When both PowerShell hosts fail to query the task (e.g., due to a timeout or locale issue) but `schtasks` confirms the task doesn't exist, the uninstall now proceeds cleanly. Only a confirmed "exists" verdict blocks uninstall. Fixes #1175.
