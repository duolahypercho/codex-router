- **Installation fix**: The installer now looks for `npm` beside the resolved `node` binary when `node` is found but `npm` is not on PATH. This fixes the "npm is required but was not found on PATH" failure when `node` is a symlink in a PATH prefix (e.g., `~/.npm-global/bin/node` → `~/.local/node/bin/node`) with the real `npm` in a directory not in the candidate list. The macOS tray's "Update & Verify" button no longer fails deterministically for this layout. Fixes #1195.
