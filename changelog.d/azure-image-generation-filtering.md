- **The Azure KMAMC Responses route no longer forwards image-generation tool declarations.** Codex declares its imagegen extension on every turn, and this route cannot serve it. The router now drops the hosted `image_generation` declaration, the `image_gen` namespace, and the flattened `image_gen.imagegen` and `image_gen__imagegen` spellings before the request leaves the router; a turn whose only tool was imagegen is forwarded with no tool list rather than an empty one. Every other provider keeps the declarations it had. Image generation is unavailable on this route, as it was before.
