- **Obscurify.ai is now a catalog-only provider.** Its OpenAI-compatible API (`https://obscurify.ai/v1`, key `OBSCURIFY_API_KEY`, endpoint override `OBSCURIFY_API_BASE_URL`) is registered for routing and credential isolation like Atlas Cloud and Together AI. It ships no preselected models: store a key, then run `./bin/curate-models obscurify` to choose models from its live catalog.
