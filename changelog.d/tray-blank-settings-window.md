- **The macOS tray no longer opens a blank "Codex Router Settings" window when it starts.** The tray's only SwiftUI scene was an empty `Settings` placeholder, and macOS 26 opens a lone `Settings` scene at launch, so every login and every tray restart put an empty window on screen; the stock Settings… menu item (⌘,) opened the same empty window. The placeholder is now a `MenuBarExtra` that is never inserted and owns no window, and Settings… (⌘,) opens the Control Center, where the settings live. The menu-bar item, the tray panel, and the Edit menu are unchanged.
