- **Responses providers can opt into pooled upstream WebSocket connections.** Generic providers use `--adapter openai-responses --transport websocket`; native traffic remains HTTP by default and opts in with `MODEL_ROUTER_NATIVE_TRANSPORT=websocket`. Canonical normalization, credential confinement, usage and response transforms remain in place. Validated handshakes, bounded queues, cancellation cleanup and identity-aware pools support connection reuse; pre-send failures fall back to HTTP, while ambiguous in-flight turns are never replayed.
