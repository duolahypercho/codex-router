- **The OpenCode Zen free tier now refuses every id it advertises.** A live probe on 2026-10-21 found that OpenCode answers `FreeTierError` on every free id it still lists and `ModelDeprecated` or "Model is unavailable" on the ones it has withdrawn, so no Zen free model can serve a request. `curate-models opencode-free` refuses them with the reason each one failed rather than handing out a route that cannot answer.
